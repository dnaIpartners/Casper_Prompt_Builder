# 프롬프트 빌더 — 기능 이관 PRD (기존 플랫폼 탑재용)

> 기획성 3D/CGI 오브젝트 이미지 프롬프트를 **4단계 위저드**로 표준화 생성하는 기능을, 별도 도구(Casper Prompt Builder)에서 **기존 플랫폼의 한 기능으로 이식**하기 위한 제품 요구사항 문서.
> 기술 스택·구현 방식은 기존 플랫폼의 표준을 따르며 본 문서 범위에서 제외한다. 본 문서는 **"무엇이 어떻게 동작해야 하는가"** 만 정의한다.

- 문서 버전: 1.0
- 원본 기준: Casper Prompt Builder 현행 구현 (`main`, 2026-08-25)
- 작성일: 2026-08-25

---

## 1. 개요

### 1.1 배경

기획전용 3D/CGI 오브젝트 이미지를 생성형 이미지 도구(예: Adobe Firefly)로 만들 때 다음 문제가 반복된다.

- 담당자마다 프롬프트 구성 순서·요소가 달라 결과 편차가 큼
- 색상을 hex 코드로 입력해도 이미지 도구에 제대로 반영되지 않음
- 렌더링 방식과 재질의 비현실적 조합(예: Clay Style + Glass)을 사전에 걸러낼 방법이 없음
- 국문 기획 의도를 영문 프롬프트로 옮기는 과정에서 정보가 손실됨

### 1.2 목표

1. 기획 정보를 **구조화된 4단계 입력**으로 받아, 규칙에 맞는 **영문 프롬프트 + 국문 해설**을 자동 생성한다.
2. 렌더링/재질의 **비호환 조합을 입력 단계에서 원천 차단**한다.
3. 생성 이력을 보관해 **이전 결과를 다시 불러와 재사용**할 수 있게 한다.
4. 기존 플랫폼 사용자가 별도 도구 없이 플랫폼 내에서 동일한 흐름을 수행할 수 있게 한다.

### 1.3 성공 기준

| 지표 | 기준 |
| --- | --- |
| 표준화 | 필수 항목만 채우면 누구나 동일한 형식(6개 항목)의 결과를 얻는다 |
| 규칙 준수 | 생성된 영문 프롬프트에 hex 코드가 포함되지 않는다 |
| 오류 방지 | 렌더링과 충돌하는 재질은 선택 자체가 불가능하다 |
| 재사용 | 이전 생성 결과를 한 번의 동작으로 현재 입력값에 복원할 수 있다 |

### 1.4 범위 (In-scope)

- 4단계 위저드 입력 흐름 및 공통 내비게이션
- 입력 항목 정의, 필수/선택 규칙, 진행률·완료 판정
- 재질 × 렌더링 호환 규칙 및 상호 배제 규칙
- AI 기반 결과 생성, 샘플(미리보기) 생성
- 결과 표시·복사, 입력 변경 감지(stale) 경고
- 생성 히스토리 조회·복원

### 1.5 범위 밖 (Out-of-scope)

- 이미지 생성 도구와의 직접 연동 — **프롬프트 텍스트 산출까지만** 담당
- 국문/영문 외 다국어 지원
- 프롬프트 프리셋/템플릿, 결과 품질 평가, 톤 조절
- 기존 플랫폼의 인증·권한·과금 체계 (플랫폼 기존 체계를 그대로 따름)

## 2. 사용자 및 시나리오

- **주 사용자**: 기획/디자인 담당자 (비개발자)
- **전제**: 기존 플랫폼에 로그인된 상태에서 본 기능에 진입한다.

### 2.1 핵심 시나리오

1. 플랫폼 내 진입점에서 프롬프트 빌더를 연다 → Step 1부터 시작한다.
2. Step 1~3에서 컨셉·오브젝트·시각 표현을 입력한다. 상단 진행률과 스텝 완료 표시로 남은 항목을 확인한다.
3. Step 4에서 **[결과 생성하기]** 를 눌러 AI 결과를 받는다.
4. 영문 Prompt / Avoid를 복사해 이미지 생성 도구에 붙여넣는다.
5. 결과가 아쉬우면 이전 단계로 돌아가 수정한다 → stale 경고를 보고 Step 4에서 다시 생성한다.
6. 과거 결과가 필요하면 **[히스토리]** 에서 항목을 찾아 현재 입력값으로 복원한다.

### 2.2 보조 시나리오

- 결과 형식을 미리 보고 싶을 때 **[샘플 출력 보기]** 로 즉시 예시 결과를 확인한다(AI 호출 없음).
- 새 기획을 시작할 때 **[처음부터 다시 생성]** 으로 입력값을 전체 초기화한다(히스토리는 유지).

## 3. 전체 프로세스

```
Step 1 컨셉 정의 → Step 2 오브젝트 정의 → Step 3 시각 표현 정의 → Step 4 결과
       (3개 필수)          (5개 필수)              (3개 필수 + 3개 선택)      (생성/복사/히스토리)
```

- 스텝 간 **자유 이동 허용**: 상단 스텝퍼 클릭으로 어느 스텝이든 이동 가능. 필수 미입력 여부는 이동을 막지 않고 Step 4에서만 생성을 막는다.
- 입력값은 스텝 이동 간 유지된다.
- Step 4의 완료 판정은 **AI 생성 결과가 존재할 때만** 인정한다(샘플 출력은 미완료).

## 4. 입력 항목 정의

### 4.1 필드 목록

| # | 스텝 | 항목명 | 입력 형태 | 필수 | 기본값 | 안내 문구 |
| --- | :---: | --- | --- | :---: | --- | --- |
| 1 | 1 | 기획전 주제 | 단문 텍스트 | ✅ | — | 무엇을 위한 기획전인가. |
| 2 | 1 | 핵심 메시지 | 단문 텍스트 | ✅ | — | 무엇을 전달할 것인가. |
| 3 | 1 | 분위기 및 감성 설명 | 장문 텍스트 | ✅ | — | 어떤 장면과 감정을 느끼게 할 것인가. 단어보다 문장, 단문보다 장문 권장 |
| 4 | 2 | 메인 오브젝트 | 장문 텍스트 + 참고 예시 | ✅ | — | 가장 중심이 되는 Hero Object. 놓인 방식까지 포함해 자유 서술 |
| 5 | 2 | 연상 요소 | 텍스트 | ✅ | — | 메인 오브젝트를 보완하는 요소 |
| 6 | 2 | 시각 강조 요소 | 텍스트 | ✅ | — | 어떤 효과를 시각적으로 가장 강하게 표현할 것인가 |
| 7 | 2 | 구성 방식 | 카드 단일 선택 | ✅ | — | — |
| 8 | 2 | 오브젝트 앵글 | 칩 단일 선택 | ✅ | — | — |
| 9 | 3 | 배경 유형 | 칩 단일 선택 | ✅ | — | — |
| 10 | 3 | 배경 표현 설명 | 장문 텍스트 | ✅ | — | 어떤 공간을 만들 것인가. 색상·재질·분위기 포함. **hex보다 자연어 색상이 정확** 힌트 노출 |
| 11 | 3 | 렌더링 방식 | 카드 단일 선택 | ✅ | — | 기법/재질 표현 방식 |
| 12 | 3 | 사실감 정도 | 토글 단일 선택 | ➖ | Balanced(중간) | 렌더링 방식을 기준으로 형태를 단순화할지 사실적으로 표현할지의 강도 |
| 13 | 3 | 디테일 강도 | 토글 단일 선택 | ➖ | 중간 | — |
| 14 | 3 | 재질 스타일 | 칩 **다중 선택** | ➖ | 없음 | 중복 선택 가능. 반대되는 마감은 동시 선택 불가 |

- 필수 항목은 **11개**. 진행률·완료 판정은 필수 11개만 기준으로 한다.
- "채워짐" 판정: 텍스트는 공백 제거 후 비어 있지 않음, 선택형은 값이 선택됨, 다중 선택은 1개 이상.

### 4.2 선택형 옵션 값

**구성 방식**
| 값 | 표시 | 설명 |
| --- | --- | --- |
| single_hero | Single Hero Object | 메인 오브젝트 단독 구성 |
| hero_supporting | Hero + Supporting | 메인 오브젝트 + 보조 오브젝트 구성 |

**오브젝트 앵글**: 정면 / 45도 / 측면 / 탑뷰 / 아이소메트릭 / 클로즈업

**배경 유형**: 그라디언트 / 단색 / 기타

**렌더링 방식**
| 값 | 표시 |
| --- | --- |
| commercial_3d | Commercial 3D CGI |
| photorealistic | Photorealistic CGI |
| semi_realistic | Semi Realistic CGI |
| stylized_3d | Stylized 3D |
| clay_style | Clay Style 3D |
| illustrative_3d | Illustrative 3D |

**사실감 정도**: Strong Stylized(매우 스타일라이즈드) / Stylized / **Balanced(기본)** / Realistic / Photoreal(매우 사실적)

**디테일 강도**: 낮음 / **중간(기본)** / 높음

**재질 스타일**: Glossy(광택) / Soft Matte(무광) / Glass(유리) / Metallic(금속) / Translucent(반투명)

### 4.3 메인 오브젝트 참고 예시 (열람 전용)

아코디언으로 제공하며, **클릭해도 입력값이 채워지지 않는다.**

| 분류 | 예시 |
| --- | --- |
| 지형 위 | 촉촉한 이끼 언덕 위에 놓인 유리병 / 모래 언덕 사이에 반쯤 파묻힌 향수병 |
| 받침·플랫폼 위 | 원형 대리석 받침 위에 놓인 립스틱 / 얇은 유리 플랫폼 위에 떠 있듯 놓인 시계 |
| 용기 안 | 투명 유리 볼 안에 담긴 진주 알갱이들 / 반쯤 물이 채워진 비커 안의 향수 원액 |
| 단독 배치 | 배경 없이 중앙에 단독으로 놓여 있는 크림 용기 / 은은한 그림자만 깔린 단독 배치의 시계 |
| 여러 오브젝트 장면 | 향수병 옆에 흩어진 말린 꽃잎과 리본 / 립스틱과 손거울, 진주 장식이 함께 놓인 장면 |

## 5. 비즈니스 규칙

### 5.1 재질 × 렌더링 호환 매트릭스 (핵심)

각 조합은 세 가지 상태 중 하나를 가진다.

- **allow**: 정상 선택 가능
- **subtle(완화 적용)**: 선택 가능하나 결과에 은은하게만 반영. 칩에 "완화 적용" 배지 + 툴팁 "완화된 형태로 은은하게 반영됩니다"
- **block**: 선택 불가. 칩 비활성화 + 툴팁 "현재 렌더링 방식과 어울리지 않는 조합입니다"

| 렌더링 \ 재질 | Glossy | Soft Matte | Glass | Metallic | Translucent |
| --- | --- | --- | --- | --- | --- |
| Commercial 3D CGI | allow | allow | allow | allow | allow |
| Photorealistic CGI | allow | allow | allow | allow | allow |
| Semi Realistic CGI | allow | allow | allow | allow | allow |
| Stylized 3D | allow | allow | subtle | subtle | allow |
| Clay Style 3D | **block** | allow | **block** | **block** | subtle |
| Illustrative 3D | subtle | allow | **block** | **block** | subtle |

- 렌더링이 미선택 상태이면 모든 재질은 allow로 취급한다.

### 5.2 상호 배제 규칙

- **Glossy(광택)** 와 **Soft Matte(무광)** 는 동시 선택 불가. 한쪽이 선택되면 다른 쪽은 비활성화되며, 툴팁에 "{상대 재질}와 동시에 선택할 수 없는 조합입니다"를 표시한다.

### 5.3 자동 정리 규칙

- 렌더링 방식을 변경하면, 새 렌더링에서 **block**인 재질은 **자동으로 선택 해제**된다. (subtle은 유지)

### 5.4 진행률 및 완료 판정

- **전체 입력 진행률(%)** = 채워진 필수 항목 수 ÷ 11 × 100 (반올림)
- **Step 1~3 완료** = 해당 스텝의 필수 항목이 모두 채워짐
- **Step 4 완료** = AI 생성 결과가 존재함 (샘플 출력은 불인정)

### 5.5 입력 변경 감지 (stale)

- 결과(샘플 포함)가 존재하는 상태에서 **어떤 입력값이든 변경되면** stale 상태로 전환한다.
- stale 상태에서는 모든 스텝 상단에 경고 배너를 노출한다.
  - Step 1~3: "현재 화면의 수정 내용은 아직 결과에 반영되지 않았습니다. [Step 4로 이동해 결과를 다시 생성] 해주세요."
  - Step 4: "아래 결과는 변경 전 입력값으로 생성된 이전 결과입니다. 위 버튼을 눌러 결과를 다시 생성해주세요."
- 결과를 새로 생성하거나 히스토리를 복원하면 stale이 해제된다.

### 5.6 결과 생성 모드

| 모드 | 동작 | 완료 인정 | 히스토리 기록 |
| --- | --- | :---: | :---: |
| 샘플 출력 | AI 호출 없이 입력값을 조합한 예시 결과를 즉시 표시. "샘플 출력 (실제 AI 생성 결과 아님)" 배지 | ✗ | ✗ |
| 결과 생성 | AI가 입력값을 바탕으로 실제 결과 생성 | ✅ | ✅ |

- **AI 결과가 이미 존재하면 샘플 출력 버튼은 비활성화**한다(실제 결과를 샘플로 덮어쓰지 못하도록). 툴팁: "실제 결과가 생성된 상태에서는 샘플 출력으로 덮어쓸 수 없습니다"
- 필수 항목 미충족 또는 생성 진행 중에는 [결과 생성하기] 버튼을 비활성화한다.
- AI 결과가 있으면 버튼 라벨을 "결과 다시 생성"으로 바꾼다.

## 6. 화면별 요구사항

### 6.0 공통 셸

| 영역 | 요구사항 |
| --- | --- |
| 헤더 | 기능명("Prompt Builder"), 부제 "기획성 오브젝트 생성을 위한 4단계 프롬프트 표준화 도구". 브랜드 표기는 플랫폼 표준을 따름 |
| 진행률 바 | "전체 입력 진행률" 라벨 + % 수치 + 바. 스크롤 시 상단 고정 |
| 스텝퍼 | 1~4 단계 원형 인디케이터 + 스텝명. 현재 스텝 강조, 완료 스텝은 체크 표시. 클릭 시 해당 스텝으로 이동 |
| 스텝 제목 | "STEP n / 4" + 스텝명 (컨셉 정의 / 오브젝트 정의 / 시각 표현 정의 / 결과) |
| stale 배너 | §5.5 |
| 하단 고정 내비 | Step 1~3: [이전] / [다음]. Step 1에서 [이전] 비활성. Step 4: [이전] / [처음부터 다시 생성] |
| 처음부터 다시 생성 | 확인창 "모든 입력값이 초기화됩니다. 계속할까요?" → 확인 시 입력값·결과·stale 초기화 후 Step 1로 이동. **히스토리는 유지** |

### 6.1 Step 1 — 컨셉 정의

- 기획전 주제 (단문, 필수) — 예시 placeholder: "여름맞이 프로모션 기획전"
- 핵심 메시지 (단문, 필수) — "더위를 식혀주는 상쾌한 순간"
- 분위기 및 감성 설명 (장문, 필수) — "이른 아침 물방울이 맺힌 유리병이 햇살에 반짝이는, 청량하고 차분한 순간"

### 6.2 Step 2 — 오브젝트 정의

- 메인 오브젝트 (장문, 필수) + 참고 예시 아코디언(§4.3). 아코디언 열림 상태는 스텝 이동 간 유지.
- 연상 요소 (텍스트, 필수) — "흩날리는 물방울, 은은하게 퍼지는 입자"
- 시각 강조 요소 (텍스트, 필수) — "표면에 맺힌 물방울이 빛을 받아 반짝이는 하이라이트"
- 구성 방식 (카드 2종 단일 선택, 필수)
- 오브젝트 앵글 (칩 6종 단일 선택, 필수)

### 6.3 Step 3 — 시각 표현 정의

- 배경 유형 (칩 3종 단일 선택, 필수)
- 배경 표현 설명 (장문, 필수) + 힌트 "색상은 Hex code보다 자연어 표현이 더 정확하게 반영됩니다. (예: #FFB6C1 → 연한 코랄핑크)"
- 렌더링 방식 (카드 6종 단일 선택, 필수)
  - 렌더링 선택 시 하단에 **"사실감 정도 · 디테일 강도 설정" 아코디언** 노출 (기본 열림, 상태는 스텝 이동 간 유지)
  - 사실감 정도: 5단계 토글, "선택 (기본값: Balanced/중간)" 배지
  - 디테일 강도: 3단계 토글, "선택 (기본값: 중간)" 배지
- 재질 스타일 (칩 5종 다중 선택, 선택) — §5.1~5.3 규칙에 따라 비활성/완화 배지/툴팁 표시. 하단 참고 문구: "'완화 적용' 표시가 붙은 항목은 선택해도 완전히 반영되지 않고 은은한 정도로만 표현됩니다."

### 6.4 Step 4 — 결과

**상단 알림**
- 필수 미입력 시: "미입력 필수 항목이 있습니다" + 항목 리스트("{항목명} (Step n)"). 각 항목 클릭 시 해당 스텝으로 이동.
- 생성 실패 시: "API 오류" 배너 + 오류 메시지(§8).

**액션 버튼**
- 좌측: [샘플 출력 보기] / [결과 생성하기 | 결과 다시 생성] (§5.6)
- 우측: [히스토리] (§6.5)

**생성 중**: "생성 중입니다..." 표시. 진행 중에는 두 생성 버튼 모두 비활성.

**결과 표시 (4블록, 순서 고정)**
| 번호 | 제목 | 내용 | 복사 |
| --- | --- | --- | --- |
| 01 | 시각 전략 | strategy (국문) | — |
| 02 | 표현 방향 | direction (국문) | — |
| 03 | Prompt 확인 (국문 해석) | prompt_ko + avoid_ko | — |
| 04 | Firefly Prompt (English) | prompt + avoid | [Prompt 복사] [Avoid 복사] |

- 복사 버튼 클릭 시 클립보드 복사 후 약 1.6초간 "복사 완료" 피드백 표시.
- 샘플 모드 결과에는 상단에 "샘플 출력 (실제 AI 생성 결과 아님)" 배지.

### 6.5 히스토리 모달

- 제목 "이전 히스토리". 배경 클릭 또는 ✕로 닫기.
- **빈 상태**: "아직 생성된 히스토리가 없습니다. '결과 생성하기'를 눌러 결과를 만들면 여기에 기록됩니다."
- **목록**: 최신순. 각 항목은
  - 헤더: `#순번 · HH:MM` (클릭 시 펼침/접힘, 다중 펼침 가능)
  - 요약: 해당 결과의 prompt_ko
  - 펼침 시: 생성 당시 입력값 14개 전체를 라벨–값 목록으로 표시 + **[현재 설정값으로 적용하기]** 버튼
- **적용**: 확인창 "현재 builder에 작성중인 내용이 선택한 항목으로 대체됩니다. 계속하시겠습니까?" → 확인 시 입력값·결과를 해당 항목으로 교체, stale 해제, AI 결과 모드로 간주, 모달 닫기.

## 7. 결과 생성 규칙

### 7.1 출력 항목 (6개, 항상 모두 포함)

| 키 | 언어 | 내용 |
| --- | --- | --- |
| strategy | 국문 | 이 컨셉을 시각적으로 어떻게 표현할지 — 번호 리스트 3~4항목 |
| direction | 국문 | 오브젝트·배경·렌더링·재질·강조 요소에 대한 구체적 시각 해석 — 번호 리스트 3~4항목 |
| prompt | 영문 | 이미지 생성 도구에 직접 입력하는 프롬프트 (하나의 자연스러운 문장) |
| avoid | 영문 | 회피 요소 |
| prompt_ko | 국문 | prompt의 국문 번역 |
| avoid_ko | 국문 | avoid의 국문 번역 |

### 7.2 영문 프롬프트 조립 순서 (필수 준수)

```
[렌더링 방식 + 재질 스타일]
→ [메인 오브젝트 + 시각 강조 요소]
→ [연상 요소]
→ [배경 유형 + 배경 표현 (자연어 색상만)]
→ [사실감 정도]
→ [디테일 강도]
→ [분위기/감성]
→ [화질]
```

### 7.3 절대 규칙

1. **hex 코드 금지**: prompt 및 배경 표현에 `#`으로 시작하는 색상 코드를 사용하지 않는다. 입력에 hex가 있어도 가장 가까운 자연어 색상으로 변환한다.
2. **재질 미지정 처리**: 재질 스타일이 비어 있으면 재질을 별도로 언급하지 않고 렌더링 방식의 기본 재질감으로 표현한다.
3. **subtle 재질**: 완화 적용 재질은 은은한 수준으로만 반영한다.

### 7.4 Avoid 기본값 및 조건부 추가

- 기본: `no text, no watermark, no logo, no cropping, no harsh drop shadows, no human figures`
- 배경 유형 = 기타 → `no background elements` 추가
- 렌더링 = Clay Style 3D 또는 Illustrative 3D → `no photorealistic texture` 추가

### 7.5 국문 번역 원칙 (prompt_ko / avoid_ko)

- 영문 prompt의 **모든 구성 요소를 누락 없이** 옮긴다(요약·생략 불가, 정보량 동일).
- 영문의 쉼표 나열·어순을 그대로 따르지 않는다. "~하며, ~하고" 식 반복 연결어미를 피하고, 2~3개의 짧은 문장으로 나누거나 관련 요소를 하나의 절로 묶어 자연스러운 한국어로 표현한다.
- `3D render`, `CGI`, `Splash` 등 디자인 현업 통용 영문 전문 용어는 번역하지 않고 그대로 둔다.

### 7.6 샘플 출력 규칙

AI 호출 없이 입력값을 단순 조합해 6개 항목을 만든다. 각 항목 앞에 "(샘플)" 또는 "(sample)" 표기를 붙여 실제 결과와 구분한다.

## 8. 입력 검증 및 오류 처리

### 8.1 생성 요청 전 검증 (화면)

- 필수 11개 미충족 → 생성 버튼 비활성 + 미입력 목록 표시(§6.4)

### 8.2 생성 요청 시 검증 (서버측, 화면 우회 방지)

아래 순서로 검사하며, 실패 시 사용자에게 다음 메시지를 "API 오류" 배너로 표시한다.

| 조건 | 메시지 |
| --- | --- |
| 생성 엔진 설정 누락 | 서버에 생성 엔진 설정이 되어 있지 않습니다 |
| 요청 형식 오류 | 요청 본문을 파싱할 수 없습니다 |
| 필수 텍스트 7개(주제·메시지·분위기·오브젝트·연상·강조·배경 설명) 공백/누락 | 필수 항목이 누락되었습니다: {항목} |
| 구성 방식/앵글/배경 유형/렌더링 값이 정의된 옵션이 아님 | {항목명} 값이 올바르지 않습니다 |
| 재질 값이 정의된 옵션이 아님 | 재질 스타일 값이 올바르지 않습니다 |
| Glossy + Soft Matte 동시 | Glossy와 Soft Matte는 동시에 선택할 수 없습니다 |
| 매트릭스상 block 재질 포함 | {재질}은(는) 현재 렌더링 방식과 어울리지 않는 조합입니다 |

- 사실감·디테일이 누락되면 기본값(Balanced / 중간)으로 보정한다.

### 8.3 생성 엔진 응답 오류

| 상황 | 메시지 |
| --- | --- |
| 안전 정책 거부 | 안전 정책에 의해 요청이 거부되었습니다. 입력 내용을 조정해 다시 시도해주세요 |
| 응답 길이 초과로 잘림 | 응답이 최대 길이를 초과해 잘렸습니다. 입력을 조금 더 간결하게 작성해보세요 |
| 응답 없음 / 형식 불일치 | AI 응답에서 텍스트를 찾을 수 없습니다 / AI 응답을 JSON으로 파싱하는 데 실패했습니다 |
| 통신 실패 | 서버와 통신할 수 없습니다 |

- 오류 발생 시 기존 결과는 제거하고 stale을 해제한다. 히스토리에는 기록하지 않는다.

## 10. 비기능 요구사항

- **보안**: 생성 엔진 인증 정보는 서버에만 존재하며 클라이언트에 노출하지 않는다. 생성 요청은 반드시 서버를 경유한다.
- **검증 이중화**: 호환 규칙·필수 검증은 화면과 서버 양쪽에서 동일하게 수행한다. 옵션 목록·매트릭스는 **단일 출처**로 관리해 양쪽이 항상 일치하도록 한다.
- **응답성**: 생성 중 상태를 즉시 표시하고, 완료 전까지 중복 요청을 막는다.
- **레이아웃**: 콘텐츠 최대 폭 약 768px 중앙 정렬. 진행률/스텝퍼 상단 고정, 내비 하단 고정. 나머지 시각 스타일은 플랫폼 디자인 시스템을 따른다.
- **접근성**: 장식용 아이콘은 스크린리더에서 숨김. 비활성 칩은 툴팁으로 사유 제공.

## 12. 수용 기준 (Acceptance Criteria)

**흐름**
- [ ] 기능 진입 시 Step 1이 표시되고, 스텝퍼 클릭으로 1~4 어디로든 이동할 수 있다.
- [ ] 스텝을 이동해도 입력값·아코디언 열림 상태가 유지된다.
- [ ] 진행률은 필수 11개 기준 %로 표시되며, 필수 항목 입력/삭제 시 즉시 갱신된다.
- [ ] Step 1~3 완료 체크는 해당 스텝 필수 항목이 모두 채워졌을 때만 표시된다.
- [ ] Step 4 완료 체크는 AI 생성 결과가 있을 때만 표시되고, 샘플 출력만으로는 표시되지 않는다.

**호환 규칙**
- [ ] Clay Style 3D 선택 시 Glossy/Glass/Metallic 칩이 비활성화되고 툴팁이 표시된다.
- [ ] Stylized 3D 선택 시 Glass/Metallic 칩에 "완화 적용" 배지가 붙는다.
- [ ] Glossy 선택 시 Soft Matte가 비활성화되고, 반대도 동일하다.
- [ ] Glass 선택 후 렌더링을 Clay Style로 바꾸면 Glass가 자동 해제된다.
- [ ] 화면을 우회해 block 조합을 요청하면 서버가 거부하고 오류 메시지를 표시한다.

**생성**
- [ ] 필수 미입력 시 [결과 생성하기]가 비활성화되고 미입력 목록이 표시되며, 항목 클릭 시 해당 스텝으로 이동한다.
- [ ] [샘플 출력 보기]는 AI 호출 없이 즉시 결과를 표시하고 "샘플 출력" 배지를 붙인다.
- [ ] AI 결과가 있는 상태에서는 [샘플 출력 보기]가 비활성화된다.
- [ ] 생성 성공 시 6개 항목이 4개 블록(01~04)으로 표시된다.
- [ ] 영문 prompt에 `#` 색상 코드가 포함되지 않는다(입력에 hex를 넣어도).
- [ ] 배경 유형 "기타" 선택 시 avoid에 `no background elements`가 포함된다.
- [ ] Clay/Illustrative 렌더링 시 avoid에 `no photorealistic texture`가 포함된다.
- [ ] Prompt/Avoid 복사 버튼이 클립보드에 복사하고 1.6초간 완료 피드백을 보인다.

**stale / 초기화**
- [ ] 결과 생성 후 입력값을 바꾸면 모든 스텝에 stale 배너가 표시되고, 재생성 시 사라진다.
- [ ] [처음부터 다시 생성]은 확인 후 입력·결과를 초기화하고 Step 1로 이동하며, 히스토리는 남는다.

**히스토리**
- [ ] AI 생성 성공 시에만 히스토리에 최신순으로 추가된다.
- [ ] 항목 펼침 시 14개 입력값과 [현재 설정값으로 적용하기]가 표시된다.
- [ ] 적용 시 확인 후 입력값·결과가 교체되고 stale이 해제된다.
